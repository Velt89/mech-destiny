2. What data we collect — and why

  • Game activity: daily check-ins, parts collected/merged/battled/traded, Blueprint Fragments, draws, shop listings and trade offers, and Pi payments you make inside the app (payment id, amount in Pi, completion status). This is the app itself: without it there is no machine, no battle, and no shop.
  • Technical data: standard server logs (request time, app version) for debugging and abuse prevention. We do not run third-party trackers or advertising SDKs in this version. [UPDATE IF THIS CHANGES — e.g. if the Pi Ad Network is added later.]
